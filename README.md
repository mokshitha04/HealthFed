🩺 Federated Multi‑Disease Prediction System
This project is an AI‑based healthcare prediction system that estimates the risk of multiple diseases using machine learning models. The system predicts diseases such as Diabetes, Heart Disease, Lung Disease, and Liver Disease based on patient health parameters.
The application integrates Explainable AI techniques (SHAP and LIME) to provide transparent explanations for predictions and uses an interactive Streamlit web interface for user interaction.
🚀 Features
1 Predicts risk of multiple diseases
2 Supports Diabetes, Heart Disease, Lung Disease, and Liver Disease prediction
3 Uses Machine Learning models trained on healthcare datasets
4 Provides risk probability and prediction results
5 Includes Explainable AI (SHAP and LIME) for model interpretation
6 Interactive Streamlit dashboard
7 Privacy‑aware architecture inspired by Federated Learning concepts

📊 System Workflow
1 User logs into the system
2 Selects the disease type
3 Enters patient health parameters
4 The corresponding machine learning model is loaded
5 The model predicts disease risk
6 SHAP and LIME generate explanations for the prediction
7 Results, risk probability, symptoms, and recommendations are displayed
▶️ How to Run the Project
Install required libraries
pip install -r requirements.txt

Run the Streamlit application
